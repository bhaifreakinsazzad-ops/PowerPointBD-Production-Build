PowerPoint Open XML Generation & Compatibility Spike

Proves deterministic PresentationML (`<p:transition>` and `<p:timing>`) template patching across 8 bilingual (Bengali + English) slides without AI-authored XML.

1. Architecture Decision Report Evidence-Backed

Slide Libraries vs. Controlled Open XML Template Patching

High-level libraries (`python-pptx`, `PptxGenJS`) generate static slide geometry (`<p:spTree>`) reliably, but cannot natively author PresentationML `<p:timing>` entrance sequences or cross-version `<p:transition>` nodes.

Chosen Strategy: Two-Stage Deterministic Open XML Patcher (`phase0_pptx_spike.py`).
Stage A: Render static bilingual text runs (`Inter` + `Nirmala UI` with `lang="bn-BD"`) and assign explicit `descr="role:..."` shape metadata.
Stage B: Patch schema-ordered `<p:transition>` and `<p:timing>` fragments strictly from versioned templates using AI-selected enum IDs (`fade`, `wipe`, `push`, `zoom`, `slide_in`).
2. Phase 0 Go / No-Go Recommendation CONDITIONAL GO

Proceed to Foundation Only After External Desktop Playback Gate

  • Illustrative checks (not run in browser): The Python engine must check generated `.pptx` archives for ZIP integrity, OPC relationship resolution, schema element ordering (`cSld → clrMapOvr → transition → timing`), shape `spid` target checks, the 5-animation cap (Slide 6), and `>6` bullets suppression (Slide 5).
  • ! GATE (External Desktop Required): Package validity is not proof of PowerPoint playback. All transitions and entrances remain marked `UNVERIFIED_EXTERNAL_DESKTOP_REQUIRED` until opened on Windows 11, macOS Sonoma, and Office 2016/2019 desktop machines and 3-second video clips are captured.
  • ✗ BLOCKED (Cinematic Tier): Remains disabled in `MOTION_POLICY` until Phase 0 desktop sign-off + first 5 paying clients + cost study (recommended).
